Actualizador de Datapacks

Sube un datapack (.zip o .rar) o un contenedor con varios datapacks dentro, de 1.21 a 26.2, y actualízalos a la versión elegida (por defecto 26.3).

Arrastra aquí tus .zip o .rar, o haz clic para elegirlos Un datapack suelto, o un contenedor con varios datapacks (carpetas, .zip o .rar) dentro

Los .rar se leen, pero el resultado siempre es .zip: el formato RAR no se puede escribir desde el navegador.

Actualizador de Plugins

Sube un plugin (.jar) o un contenedor (.zip o .rar) con varios plugins dentro, y actualiza el api-version de plugin.yml / paper-plugin.yml.

Arrastra aquí tus .jar, .zip o .rar, o haz clic para elegirlos Un plugin suelto, o un contenedor con varios .jar dentro

Un servidor más antiguo que el api-version rechaza cargar el plugin. Si tu servidor aún no está en 26.3, elige la versión de tu servidor. Cambiar el número no recompila el código: si el plugin usa NMS o APIs cambiadas, hay que recompilarlo.

Actualizador de Mods

Sube un mod (.jar) o un contenedor (.zip o .rar) con varios mods de Fabric, Quilt, Forge o NeoForge, y actualiza la versión de Minecraft que declaran.

Arrastra aquí tus .jar, .zip o .rar, o haz clic para elegirlos Un mod suelto, o un contenedor con varios .jar dentro (fabric.mod.json, quilt.mod.json, mods.toml)

Esto cambia solo la metadata de compatibilidad. Un mod compilado contra nombres intermediarios de Fabric o contra APIs cambiadas necesita recompilarse desde su código fuente para funcionar en 26.x.
